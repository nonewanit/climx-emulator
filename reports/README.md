# Reports

Course deliverables live here (or are linked from here) so the GitHub repo is a
complete submission to the professor.

| When | Deliverable | Status |
|---|---|---|
| Week 9 (~Nov 15, 2026) | Mid-term report (lite pipeline + baselines + first submission) | draft |
| Week 15 (Dec 21–27) | Poster | — |
| Weeks 16–17 (~Jan 8, 2027) | Final report + code (official split, vs 1–2 baselines, leaderboard position) | — |

Writing conventions (from the course logistics):

- NeurIPS format, English (the proposal in [`../proposal/proposal/main.tex`](../proposal/proposal/main.tex) is the template).
- Since ClimX ends before the semester ends, the final report compares against
  1–2 baselines on the official split **and** reports the leaderboard position.
- The data source for all result tables is [`results/scores.md`](../results/scores.md) (+ the per-run logs under `results/runs/`).
